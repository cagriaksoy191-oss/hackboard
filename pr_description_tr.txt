🔒 Yedekleme (Backup) API endpointlerindeki yetkisiz erisim zafiyeti giderildi

🎯 **What:** The vulnerability fixed
`server/routes/backup.js` icerisindeki `/export`, `/health` ve `/import` endpointleri kullanici kimligini dogrulamadan calisiyordu. Bu durum yetkisiz kullanicilarin hassas yedekleme verilerine erismesine neden oluyordu.

⚠️ **Risk:** The potential impact if left unfixed
Herhangi bir saldirgan veya yetkisiz kullanici tam veritabani dump'ini cekerek, gorevler, mesajlar, kullanici profilleri ve aktivite loglari gibi hassas bilgileri ele gecirebilirdi. Daha da kotusu, modifiye edilmis bir veritabanini sisteme yukleyerek uygulamadaki tum verilerin uzerine yazabilirdi.

🛡️ **Solution:** How the fix addresses the vulnerability
`server/routes/backup.js` icerisine bir kimlik dogrulama (authentication) middleware'i (`authMiddleware`) eklendi. Bu middleware, API isteklerindeki `x-user-id` basligini kontrol ediyor ve verilen ID'nin veritabaninda gecerli bir kullaniciya ait olup olmadigini dogruluyor. İstemci tarafindaki API istemcisi (`client/src/lib/api.js`), localStorage uzerinden alinan `X-User-Id` bilgisini giden tum API isteklerine otomatik olarak ekleyen bir Axios interceptor ile guncellendi.
